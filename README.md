# Флора-учёт

Приложение для автоматизации работы небольшой цветочной лавки.

Помощник флориста: от букета до заказа.

---

## Возможности

- **Собрать букет** — калькулятор стоимости (срезка + упаковка + работа).
- **Мои букеты** — список собранных букетов, статус, удаление.
- **Списание** — учёт увядших, бракованных и побитых цветов.
- **Отчёт по списаниям** — за день, неделю, год.
- **Календарь** — предзаказы по датам.
- **Клиенты** — база клиентов и их предпочтений.
- **Аналитика** — сводка за период (собрано, продано, прибыль, списано).
- **График** — столбчатая диаграмма прибыли и продаж.
- **Справочник** — цвета и упаковки.

---

## Требования

- **ОС:** Windows 10/11 или Linux.
- **Python:** 3.9+.
- **Библиотеки:** PyQt5, pyphen.

---

## Установка и запуск

### Вариант 1. Через Python

1. Установите Python 3.9+ и PyQt5:

   pip install PyQt5 pyphen

2. Перейдите в папку проекта:

   cd flower_shop

3. Запустите приложение:

   python3 main.py

### Вариант 2. Через готовый исполняемый файл

1. Откройте папку dist/Flora/.
2. Запустите файл Flora.

## Как пользоваться

### Собрать букет

1. Откройте главное окно → нажмите карточку «Собрать букет».
2. Выберите цветок из списка, укажите количество.
3. Выберите упаковку и её размер.
4. Введите стоимость работы флориста.
5. Введите название букета.
6. Нажмите «Рассчитать» — внизу появится итоговая цена.
7. Нажмите «Сохранить» — букет появится в разделе «Мои букеты».

### Мои букеты

- Показывает все собранные букеты с датой, составом, ценой и статусом.
- Двойной клик по колонке «Статус» переключает букет между «В наличии» и «Продан».
- Двойной клик по колонке «Было всего» позволяет изменить количество.
- Удаление: кнопка «Удалить выбранные» → отметьте галочками → «Удалить отмеченные».

### Списание

1. Откройте карточку «Списание».
2. Выберите цветок из списка.
3. Укажите количество.
4. Выберите причину: увядание, бой или брак.
5. Нажмите «Списать» — данные попадут в отчёт.

### Календарь

- Показывает календарь с предзаказами.
- Кнопка «Добавить заказ» — создать новый заказ на выбранную дату.

### Клиенты

- Таблица всех клиентов с именем, телефоном и предпочтениями.
- Кнопка «Добавить клиента» — открыть форму.
- Поле «Поиск» — найти клиента по имени или телефону.

### Аналитика

- Кнопки «За день» и «За неделю» переключают период.
- Показывает: сколько букетов собрано, какая прибыль, сколько списано.

### График

- Столбчатая диаграмма прибыли и продаж за выбранный период.

### Справочник

- Вкладка «Цветы» — список цветов с ценами.
- Вкладка «Упаковки» — список упаковок с ценами.

## Устранение возможных проблем

### Приложение не запускается через Python

Проверьте:
- Установлен ли Python 3.9+ (python3 --version).
- Установлены ли библиотеки (pip install PyQt5 pyphen).
- Запускаете из корня проекта (python3 main.py).

### Не открывается исполняемый файл

- Запускайте файл Flora из папки dist/Flora/ — рядом должна быть папка _internal.
- На Linux может потребоваться: chmod +x dist/Flora/Flora

### База данных повреждена

- База данных — это файл flower.db в корне проекта.
- Для восстановления замените файл на резервную копию.

### Приложение зависает

- Закройте и запустите заново.
