# Бэклог продукта «Флора-учёт»

Список идей и улучшений для следующих версий приложения.

## Приоритет 1 (важное)

- Экспорт отчётов в Excel и PDF.
- Печать чеков для клиентов.
- Уведомления о предзаказах (за день до праздника).
- Автоматическое резервное копирование базы данных.

## Приоритет 2 (полезное)

- Авторизация для нескольких пользователей.
- Разделение прав: флорист, владелец.
- Поиск по составу букета (не только по названию).
- Массовое редактирование цен на цветы.
- Фильтр списаний по причине (увядание, бой, брак).

## Приоритет 3 (на будущее)

- Мобильная версия.
- Интеграция с онлайн-кассой.
- Отправка SMS-уведомлений клиентам.
- Синхронизация между несколькими лавками.
- Экспорт данных в 1С.

## Известные баги

- При большом количестве записей (>1000) возможны задержки при открытии отчётов.
- Не реализовано удаление сразу нескольких букетов из окна «Мои букеты» по имени (исправлено удалением по id).
- Возможны проблемы с кириллицей при работе SQLite LOWER() на некоторых ОС (исправлено через Python).

## Идеи от пользователей

- Хочу видеть топ-5 самых продаваемых цветов.
- Нужна возможность отметить букет как «подарок».
- Хочу добавлять фото букета.
